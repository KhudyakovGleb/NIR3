## Описание проекта / Project Overview

Данная работа направлена на разработку метода интегральной оценки значимости проблем городской среды на основе анализа данных, полученных из цифровых каналов обратной связи граждан. Проект включает в себя сбор, агрегацию и анализ пользовательских обращений, автоматизированную классификацию тем и проблем, а также визуализацию результатов для последующего использования в процессе городского управления.

## Как запустить / How to Run

1. Убедитесь, что у вас установлен [Poetry](https://python-poetry.org/).
2. Инициализируйте окружение:

```bash
poetry install
```

3. Активируйте окружение:

```bash
poetry shell
```

4. Запустите основной скрипт или ноутбук анализа данных.
